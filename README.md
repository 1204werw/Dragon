# 🐉 BF 網頁基本架構

## 📌 專案介紹
本專案以 Roblox 遊戲《Blox Fruits》為主題，設計一個結合黑色、橘色與龍元素風格的網頁，主要用於展示 HTML、CSS 與 JavaScript 的基本架構及應用。

## 🎨 網頁特色
- 黑色與橘色的主題設計
- 龍元素風格的視覺呈現
- 網頁文字與標題排版
- 表格展示
- 圖片展示與放大功能
- 影片播放
- 導覽列與下拉式選單
- 側邊快速導覽
- 回到頁首功能
- 基本網頁互動效果

## 🛠️ 使用技術
- HTML：建立網頁基本結構
- CSS：設計網頁樣式與版面
- JavaScript：實現網頁互動功能

## 🌐 專案目的
透過本專案練習網頁設計與前端開發，了解網頁的基本結構、版面配置、視覺設計及互動功能，並作為未來網站開發與功能擴充的基礎。

## 📁 專案性質
本網站目前以基本網頁架構及功能展示為主，持續學習、設計與完善網頁內容。
